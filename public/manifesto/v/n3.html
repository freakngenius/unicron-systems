Anatomy of a Living Operation.
One organism, five primitives, one invocation.

The factory got redesigned. This is what's inside. Cut open a Unicron operation and you find five biomimetic primitives braided into a single nervous system — each doing the job evolution already perfected.

The Cross-Section
Reading the body
Five organs. One organism. Each primitive is doing a job that evolution already got right — you're just hosting it in a new substrate.
Direction
I
The one human. Taste, judgment, intent. Not scalable. Not replaceable. The scarcest resource in the system.
Elder
I·II
The continuity keeper. Holds seven-generations memory — prior promises, existing users, what we said we would do. Advises intent before it hits the substrate. Non-blocking, but loud.
Taboo Keeper
II
The refusal organ. Maintains the list of things this operation will not do — regardless of whether a user asks, a model suggests, or a metric rewards it. Can veto an invocation at the gate.
Mycelium
III
The shared substrate. All agents read and write to the same memory (Notion, vector store, state graph). Coordination comes from the substrate — not from messages.
Hive
III
Role-specialized agents (CEO, Research, Ops, CMO, CTO). Each does one thing well. Each can veto or amplify the others.
Starling
III
Bounded peer attention. Agents watch a small fixed set of neighbors — not a global bus. State propagates faster than any orchestrator could route it.
Slime Mold
III
Many approaches launched in parallel. Results reinforce the winners; losers dissolve. You don't guess the right workflow — the system finds it.
Ants
IV
State lives on the artifact, not the agent. Workers are amnesiac; the work product remembers. Every claim file, letter, and log carries the pheromone.
Ambient Labor
V
The execution layer. Agents, models, APIs, tools. Commodity. Interchangeable. Near-zero marginal cost. Whatever's cheapest and best at the moment of invocation.

One invocation, walked.

01
The operator writes one sentence of intent. "Handle this claim end-to-end."
02
Intent passes the refusal gate. The Taboo Keeper checks against the "will not do" list; the Elder checks against prior commitments. Intent proceeds, is modified, or is sent back.
03
The gated intent drops onto the mycelial substrate. No one is notified. The specialists read the substrate when they wake.
04
Role agents pick up the thread. Each does what its role does; they pass compressed structured signals, not prose.
05
The Ops agent forks three parallel approaches. They run in parallel on ambient labor. Cheap. Fast. Disposable.
06
Results deposit onto artifacts. Evidence bundle. Dispute letter. Negotiation log. Each carries a confidence pheromone.
07
Peer agents watching each other (starling) amplify or flag. The Taboo Keeper re-checks artifacts before they leave the organism. The strongest path reinforces; the others dissolve.
08
The outcome returns to the operator. One decision point for a human. Approve, veto, redirect.
09
Every artifact, pheromone, verdict, and refusal stays on the substrate. The Elder updates the continuity log. The organism is now smarter than it was this morning — and its "will not do" list is slightly longer.

Production specs.

Substrate
Notion (today) → vector-indexed state graph (Phase 2). All agents read on session start, write net-new facts on session end.
Specialists
CEO, Research, Ops, CMO, CTO, Elder, Taboo Keeper. Each a Perplexity Space with a scoped memory page. No agent operates outside its role.
Refusal gate
Taboo Keeper holds an explicit "will not do" register (Notion page). Every invocation passes the gate before dispatch; every outbound artifact passes it again before send.
Continuity
Elder maintains the seven-generations log — prior customers, prior promises, prior commitments. Reviewed weekly; referenced on every non-trivial invocation.
Signal format
Structured schemas — claim-shape, lead-shape, anomaly-shape. No free-text walls between agents.
Peer attention
Each agent subscribes to 2–3 peers' latest artifacts. No global broadcast. Slack is the event surface.
Parallelism
Default: 3 forks per non-trivial task. Generator-Verifier gate prunes to the strongest within 2–3 loops.
Artifact state
Every work product is tagged with source, confidence, and prior-version pointer. The artifact is the memory.
Learning loop
Weekly rollup: which primitives fired most, which paths reinforced, which exceptions broke them. Feeds next week's memory.
Failure modes
Ant mill (stale pheromones), starling panic (cascading bad signal), mycelial poison (bad substrate writes), premature prune (exploration starved).

You don't run a company. You run an organism.

This is the thing that couldn't exist 18 months ago. Not a SaaS. Not a BPO. Not consulting. An operation that invokes its own labor, remembers on the artifact instead of in the employee, and gets measurably smarter between Monday and Friday — and which, critically, can still say no.

Two humans direct it. Perplexity Computer and friends execute it. Everything in the middle — the substrate, the specialists, the peer attention, the parallel forks, the pheromone trails, the refusal gate, the continuity log — is Unicron's actual IP. That's what the competition judges need to see, and what the market will eventually buy.

Every operation we run deposits attention-capital onto the substrate. Every artifact carries pheromone. Every refusal carries a precedent. Every week the organism knows more exceptions, more edge cases, more shortcuts — and more things it will not do — than it did the week before. Code is ambient. Data is ambient. Orchestration intelligence is not. Refusal is not.

A system that cannot refuse is not intelligent. It is only fast.
