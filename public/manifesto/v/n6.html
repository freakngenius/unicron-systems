The Five, Spec'd
Signal strength as pathway width
Pattern 01 · Mycelium

Signals that persist.

Agents drop typed signals into a shared substrate. Strong signals reinforce. Weak signals decay. Memory becomes self-prioritizing — no one curates it.

Data
One signal table. Columns: topic, type, source_agent, strength, last_touched, ttl_days. Types: FACT · QUESTION · PATTERN · RISK.
Tools
Supabase table or Notion DB. Nightly n8n job decrements strength and archives below threshold. Any agent reads/writes via MCP.
Process
Every session ends with "drop 1–3 signals." Every session starts with "read top-10 strongest on my topic." Decay tick runs nightly.
Build Time
3 days.
When to Reach
Multiple agents whose work should inform each other without a central planner. Memory that stays fresh without manual curation.
Why it matters
Fixes "agents don't remember" without turning memory into a swamp. Auto-prunes stale facts. A direct upgrade to the Notion Agent Memory already running — same shape, but load-bearing.
Refusal · Decay
Every signal carries a mandatory ttl_days. The substrate forgets by default. Signals that aren't re-touched by a real session decay to archive — no override, no pinning by the author. The forest eats its own dead; this memory does too.
Assembly line with validated contracts
Pattern 02 · Beehive

Specialists with strict handoffs.

Highly differentiated roles, each one doing its job perfectly, coordinated by typed contracts. The dance is the schema — if it doesn't validate, it bounces back.

Data
Per-role memory page. Input/output JSON schema for every handoff. Schema is the contract.
Tools
Perplexity Spaces (already live). Notion for memory. Slack as the coordination surface. Schemas enforced by a thin validator — Zod or a Claude verifier step.
Process
Pick one end-to-end task. Build the line: Research → Strategy → Copy → Send. Each handoff validates or bounces. Max 2 retries before human escalation.
Build Time
5–7 days.
When to Reach
A repeating end-to-end workflow with clear stages. You need reliability more than exploration.
Why it matters
Closest to what's already live. Formalizing the handoff schemas is what turns "4 agents in Slack" into a factory. Quality stays high at throughput because the contract catches drift before it escapes the stage.
Refusal · Dissent
Every downstream role is a validator, not a receiver. Strategy can reject a lead as out-of-ICP. Copy can reject an angle as off-brand. Send can refuse a draft. Two bounces at any stage escalates to the Elder — the line does not grind on through a bad handoff. The scout's dance can be ignored.
Fan-out, independent work, aggregate
Pattern 03 · Ant Colony

Many parallel, no hierarchy.

N cheap workers, no coordination, no plan. Each does one micro-task. Emergence comes from aggregating many independent attempts into one cluster map.

Data
A target list (the "food" — URLs, names, docs). A standard output JSON schema. An aggregator/dedupe function.
Tools
Claude Agent SDK batch dispatch, or Manus / Jules for fan-out, or a queue feeding 50 Computer tabs. Output to a single Supabase table. A summarizer pass at the end.
Process
Define the micro-task (≤ 90 seconds of work each). Define the output JSON. Fire 50–500 in parallel. Aggregate. Cluster. Surface emergent patterns.
Build Time
2–3 days.
When to Reach
You need breadth fast. Scraping, enrichment, mass evaluation, pattern discovery across a large candidate set.
Why it matters
Highest immediate leverage for discovery itself. Point it at 200 contractor websites, 500 PA subreddit posts, 100 estate-attorney Yelp reviews — real pain language, named tools, named prices, in an afternoon. The unfair advantage for vertical hunting.
Refusal · Rest & Evaporation
NO_SIGNAL is a first-class output. A worker that finds nothing says so, loudly, and the aggregator must respect low-confidence nulls — it cannot reach past them to invent a pattern. Pheromones in the candidate pool decay on a scheduled tick; runs that stop producing signal are retired without ceremony. The brood rests.
Local attention only, coherence emerges
Pattern 04 · Murmuration

Each watches seven.

Every agent watches only its nearest N neighbors. No leader, no global plan. Coherent group motion emerges from local rules alone.

Data
A time-ordered recent-activity feed of peer outputs. A simple local update rule per agent ("be inspired by the last 3, differentiate").
Tools
Supabase realtime channel or Notion DB sorted by last-modified. Agents poll top N peers before each output.
Process
Best for evolving outputs. 7 agents iterate. Each sees only the most recent 3 peer attempts. Run 20 cycles. Watch convergence (consensus) or divergence (need tighter rule).
Build Time
4–5 days.
When to Reach
Evolving variants — landing page copy, cold email tests, pricing experiments. When you want many attempts that influence each other without a central editor.
Why it matters
How you get multi-variant copy, pricing, messaging without a central plan. The output space explores itself. Looks magical in a demo because you can show the swarm converging on a direction nobody specified.
Refusal · Break-off
An agent whose local rule is violated — the neighbors are drifting toward taboo copy, a banned claim, a compliance line — peels off from the swarm and posts a dissent signal instead of another variant. Consent is structural: staying in the murmuration is a choice re-made every cycle, not a default.
Selection pressure as adaptive network
Pattern 05 · Slime Mold

Explore many, prune hard.

Explore many paths in parallel. Score each. Kill the weak. Reroute resources to the strong. Repeat until one or two remain.

Data
Candidate registry: id, hypothesis, score, last_evaluated, resource_share. A scoring function — judge agent OR a hard metric (revenue, replies, signups).
Tools
Notion or Supabase for the registry. A judge agent (Claude or Computer) scoring against explicit criteria. Scheduled prune job (n8n or scheduled tasks).
Process
Generate 10 candidates. Run in parallel. Score. Prune bottom 50%. Double resources on survivors. Repeat weekly until 1–2 remain.
Build Time
3–4 days.
When to Reach
Any "narrow the field" decision. Verticals, ICPs, pricing, channels, positioning.
Why it matters
This is literally the discovery sprint we're running right now, unformalized. Building it makes the selection engine reusable forever. Most demoable to judges: "we have a machine that picks our company for us."
Refusal · Abstain & Withdraw
The judge can return NO_CANDIDATE_MEETS_THRESHOLD — "insufficient signal, declining to act" as a first-class verdict. A slime mold with nothing worth routing to does not route. Better to kill the generation and re-seed than to pick a winner that doesn't clear the bar.

The order to build them in.

Not all five at once. There's a sequence that compounds — each pattern gives leverage the next one needs. Start where the discovery phase is right now, end with the showpiece.

Run it on the discovery surface this week. Scrape candidate verticals, adjacent markets, buyer forums. You'll surface markets the team hasn't seen yet and validate or kill current leads with real language.

The showpiece. Variant generation at scale for copy, pricing, offers. Last because it needs a product to apply to — and because it's the most impressive thing to show on pitch day.
Week 6–8

No single pattern is the system. They layer.

In a full operation, all five run at once. Ant Colony feeds Slime Mold with candidates. Slime Mold prunes to a shortlist. Beehive runs production pipelines on the shortlist. Mycelium keeps the whole thing remembering what it's learned. Murmuration generates variation inside the constraints the others create.

And each one carries its own refusal — decay, dissent, rest, break-off, abstain. Without them, a coordination primitive becomes an extraction primitive. The organ and the organ's "no" ship together.

One organism. Five organs. Five refusals. Coordinated ambient labor that can also stop.

The prototypes are cheap. The compounding is where the value is. The refusal layer is what keeps the compounding from going rogue.
